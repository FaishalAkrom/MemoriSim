# Memory Manager
Pengelolaan Memori Komputer Menggunakan Algoritma FIFO, LRU, dan Optimal (proyek akhir Sistem Operasi).

## Cara menjalankan
1. Ekstrak ZIP, buka folder `memory-manager` di Visual Studio Code.
2. Buka terminal, jalankan `npm install`.
3. Jalankan `npm run dev`, lalu buka alamat localhost yang tampil di browser.

Build produksi: `npm run build`. Logika algoritma ada di `src/algorithms/`, terpisah dari tampilan.
